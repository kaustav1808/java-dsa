1. WHAT TO STUDY TODAY

   Return the best single-branch gain upward while updating a global best using both
   branches.

   Key ideas to understand before coding (from today's problems):
   - Post-order height; at each node update best = max(best, leftHeight + rightHeight).
   - Post-order: each node returns its best single downward branch (ignore negative
     branches) and updates a global best using both branches.
