1. WHAT TO STUDY TODAY

   Map first-seen index for transformed prefix sums (0/1 to -1/+1) and for remainders
   mod K.

   Key ideas to understand before coding (from today's problems):
   - Treat 0 as -1; the longest subarray with sum 0 is found by storing the first index
     of each prefix sum (balance).
   - Count prefix-sum remainders; normalise negative remainders with ((x % k) + k) % k;
     seed remainder 0 with count 1.
