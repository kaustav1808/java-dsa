1. WHAT TO STUDY TODAY

   Return a node when found; the LCA is where left and right both return non-null.

   Key ideas to understand before coding (from today's problems):
   - Post-order: if p and q are found in different subtrees, the current node is the
     LCA; otherwise pass up whichever side found something.
