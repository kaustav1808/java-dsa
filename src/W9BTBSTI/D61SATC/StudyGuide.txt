1. WHAT TO STUDY TODAY

   Preorder with null markers; build a tree from preorder and inorder using an index
   map.

   Key ideas to understand before coding (from today's problems):
   - Pre-order with a null marker (e.g. "1,2,#,#,3,4,#,#,5,#,#") and a recursive reader.
   - The first preorder value is the root; its position in inorder splits left and right
     subtrees (use a value -> index map).
